Stage 1 · the object

Hypercubes are bit-flip graphs

The hypercube Qn has one vertex per binary string of length n, and an edge wherever two strings differ in a single bit. Q1 is an edge, Q2 a square, Q3 a cube, Q4 the tesseract spinning above. Hover a vertex to light up its bit-flips.

Stage 2 · the question

Spanning trees, and a formula with no story

A spanning tree connects every vertex using no loops. The square has exactly four — delete any one edge of its cycle. Step through them:

tree 1 / 4

In 1999, Stanley's Enumerative Combinatorics (Example 5.6.10) recorded the general count — proved by multiplying matrix eigenvalues, a proof that verifies everything and explains nothing:

c(Qn) = 22n−n−1 · ∏k kC(n,k)   → 1, 4, 384, 42 467 328, 2.08×1019, …

What nobody has found — not in 1999, not since — is a bijective proof: an explicit rule matching each spanning tree with a sequence of independent choices, the way Prüfer's classic bijection explains Cayley's nn−2. That missing proof is this project's summit.

Stage 3 · the tool

Play the burning game

Assign each non-root vertex a resistance. Fire starts at the root 00; a vertex ignites when its number of burning neighbors exceeds its resistance. If everything burns, the assignment is a parking function.

Click the yellow numbers to set resistances, then ignite. Can you find all four parking functions?

Two facts make this game deep. The order of burning never matters (the fire is abelian). And — a theorem for every connected graph — the parking functions are exactly as numerous as the spanning trees. Whatever we learn about parking functions is secretly about trees.

Stage 4 · rigidity

Maximal parking functions

Raise any entry of a maximal parking function and the fire stalls. The square has three: (1,0,0), (0,1,0), (0,0,1) — and by a rigidity theorem every maximal parking function of a graph has the same total sum, g = E − V + 1. Their counts are Tutte-polynomial evaluations, and they grow fast:

The project's decade-old goal ("a bijection between them") was impossible as written — the real program, already hinted at by Benson–Chakrabarty–Tetali in 2010, is to use the maximal parking functions to organize everything else. Which is exactly what happened next.

Stage 5 · first theorem

The box partition

Give every parking function its canonical burn order: when several vertices could ignite, always burn the smallest label. Sorting parking functions by that order turns out to slice them into boxes — intervals [bottom, top] — that tile everything perfectly, one box per maximal parking function:

This box partition theorem (2026) is why the project's Rust tool qpark can list each maximal parking function of Q4 exactly once — all 3 040 575 of them in 1.5 seconds, with the spanning-tree count and the full Tutte diagonal T(1,y) falling out of the same pass. Stage 6 · the pivot

Hypercubes are prisms

Qn is two copies of Qn−1 (the levels) plus one vertical rung per vertex. Any spanning tree uses some set S of rungs — its vertical support. Sort the square's four trees by their rungs:

The support-product theorem

#trees with rung set S  =  ½ · c(base) · 2|S| · F(S)

where F(S) counts the ways to break the base into |S| loop-free pieces, one holding each rung vertex. Discovered by exhaustive census (verified for every one of the 3 + 15 + 255 supports of Q2, Q3, Q4 — the last over all 679 477 248 tree–root pairs), then proved in three paragraphs. Check it against the real Q3 census:

Summing over S and iterating over the n dimensions, the exponents combine by Pascal's rule and Stanley's formula falls out whole — a new, elementary, induction-on-dimension derivation. But the eigenvalue-free bijective proof demands more: an explicit rule extracting, from each tree, the recipe of independent choices the right-hand side describes.

Stage 8 · proved august 2026

The class-level law

Zoom all the way in. Delete a tree's rungs, flatten both levels onto the base: you get a multiset U of base edges (doubled = used in both levels, single = carries a free bit — which level?). The finest possible counting statement is now a theorem:

#trees in class (S, U)  =  d(S, U) · 2|S|−1

where d counts the ways U splits into (base spanning tree) ⊎ (S-rooted forest) — and every split shows up in person, as the "polarized" tree carrying the spanning tree on level 0 and the forest on level 1:

Proof: give every base edge its own variable, watch the prism's weighted Laplacian split in two under the level swap, and read off one coefficient. Verified beforehand on all 2 459 292 classes of Q3 and Q4. With this, every counting statement in the program is proven, down to the last stratum.

Stage 9 · the hidden dials

Spins: every rung is a switch

Pick up a spanning tree of the prism and root it — grab it by any one vertex and let the rest dangle. Now every rung in the tree gets a spin: look at its two ends, and ask which one is closer to your hand. If the closer end is on level 0, the spin is 0; if on level 1, the spin is 1. A tree with |S| rungs carries |S| of these hidden switches.

Two facts make the spins magical. First — verified exactly on every rooted tree of nine different prisms — the switches are perfectly free: among all rooted trees with the same rung set, every combination of spin values occurs equally often. Second, a two-line theorem tells us exactly which trees have all switches at 0:

All spins 0 ⟺ the tree is "polarized": a base spanning tree on level 0, a rooted forest hanging on level 1, root in your hand at level 0. Why: the map of the tree's pieces is itself a tree, alternating between levels; if every "toward the root" arrow lands on level 0, the level-0 side can't have any parent at all — so it's one single piece, and everything else hangs off it by one rung each. Verified over 108 384 rooted trees: zero exceptions.

And crucially, the switches can be operated: a rung whose fiber dangles by a single edge is flipped by moving that one edge to the other level; every other rung reduces to that case by a shrink-and-restore recursion (this is Bernardi's 2012 induction, turned into an algorithm). Flip all the 1s to 0s, remember what you flipped, and any rooted tree becomes a frozen polarized one — reversibly.

Stage 10 · the machine, running

Stage 11 · the summit

A Prüfer code for the cube

Do the factory once to the cube (getting a square tree and colors), then again to the square trees, and again — and every rooted spanning tree of the cube boils down to seven dials: three with 2 positions, three with 4, one with 6. Below is the real thing — the table behind these dials was computed by the verified bijection, all 3 072 entries. Turn the dials: every setting is a different rooted tree, every rooted tree has exactly one setting.

2·2·4·2·4·4·6 = 3 072 dial settings = 8 roots × 384 spanning trees — and for general n the dials multiply to ∏(2k)^C(n,k): Stanley's formula, proved by matching things up.

Where this stands, honestly. The construction above is implemented and machine-verified: the per-level bijection exhaustively on six base graphs; all 3 072 cube trees onto their exact box with perfect round-trips; 200/200 sampled round-trips at n = 4 in a box of 679 477 248. The written proof for all n rests on two new theorems plus Bernardi's published induction. Two things remain before "final": human review of the write-up (a machine checked the algorithm, not the prose), and — as a refinement — replacing the one recursive ingredient, the spin flip, with a closed formula. The problem Stanley recorded in 1999 has, at minimum, an executable answer.
